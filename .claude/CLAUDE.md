# Stonyx

Stonyx is a modular Node.js framework with a plug-and-play architecture.

See [docs/index.md](../docs/index.md) for full documentation including conventions, modules, lifecycle, and API reference.

## Agent Notes

- This is an ES Modules project (`"type": "module"` in package.json)
- Package manager: pnpm
- Test runner: `stonyx test` (QUnit-based)
- Linting: `@abofs/code-conventions`
